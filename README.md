## 📌 这是什么？

这是一个 WorkBuddy AI Skill，专为**旅游研学行业**的微信公众号运营设计。你只需要交一份 Word 文档或活动文案，AI 自动完成：

1. ✅ **文案润色与重构**——根据受众群体调整语气，12 个标准板块自动取舍
2. ✅ **微信兼容 HTML 排版**——100% 通过微信后台过滤检查，零手动修复
3. ✅ **封面海报生成**——2 张候选海报，含文字排版和二维码预留空间

> 传统人工排版：3-5 小时/篇，外包 300-800 元/篇。  
> 本 Skill：**5 分钟，成本趋近于 0**。

## 🧠 工作流架构（5 阶段）

```
阶段 0: 关键信息确认（防幻觉）
    ↓  用户逐项确认价格/日期/年龄等 8 项关键数据
阶段 1: 内容分析 + 视觉风格自动选取
    ↓  AI 按内容主题自动匹配配色方案
阶段 2: 文案重构与结构化
    ↓  12 个标准板块按需取舍
阶段 3: 微信兼容 HTML 排版 + 兼容性自查
    ↓  8 项格式检查，确保 100% 通过微信后台过滤
阶段 4: 封面海报生成（2 选 1）
    ↓
交付三件套：文案预览 + HTML 代码 + 封面海报
```

### 关键设计

- **防幻觉拦截（阶段 0）**：大模型容易自己编造价格和日期。本 Skill 在生成内容**之前**强制用户确认所有关键数据，不确认不往下走。
- **兼容性铁律（阶段 3）**：提炼了微信公众号后台的 6 类 HTML 过滤规则，写成硬性约束嵌入 AI 执行指令——`<div>` → `<section>`、禁止外部样式表等。
- **模板化驱动**：AI 在"填空"上的准确率远高于"从零构建"。每个视觉模块都有预设的 HTML 骨架模板。

## 📋 微信兼容性要点

本 Skill 生成的 HTML 严格遵守以下规则：

| 规则 | 原因 |
|------|------|
| ❌ 禁止 `<div>`、`<ul>`、`<li>` | 微信后台会自动清除这些标签 |
| ❌ 禁止 `<style>`、`<link>` | 外部/内部样式表会被过滤 |
| ✅ 仅用 `<section>`、`<p>`、`<span>` | 微信允许的安全标签 |
| ✅ 所有样式内联（inline CSS） | 唯一能在微信中生效的样式写法 |
| ✅ 表格使用 `<table>` 系列标签 | 微信对表格标签保留 |
| ✅ 最大宽度 600px | 微信公众号内容的推荐宽度 |
